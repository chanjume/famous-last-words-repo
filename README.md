# Famous Last Words at 1 Percent

A phone's last words as its battery hits 1 percent, written by a small
Node program that writes one line to `/output/entry.txt`.

> I carried 4,127 photos, 312 unread emails, and the Wi-Fi password you never wrote down. That one dies with me.

Run with `node main.ts` (Node 22). The line is 110 characters, inside the
1–199 character gate, in the phone's own voice, with a concrete inventory
and a final twist.
